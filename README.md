# Healthcare-Data-Analysis-Dashboard-Power-BI
(1) Project Overview:
The Healthcare Analytics Dashboard is a dynamic and interactive Power BI dashboard designed to analyze key healthcare metrics such as billing amounts, medications, hospital performance, and doctor distribution. It provides a unified view for understanding medical and operational insights from hospital data.


(2) Short Description / Purpose:
The dashboard enables users to explore healthcare trends by medical condition, patient demographics, and hospital performance. It helps healthcare administrators, analysts, and policymakers make data-driven decisions to improve efficiency, reduce costs, and enhance patient care outcomes.


(3)Data Source:
Kaggle – Hospital Dataset


(4) Features / Highlights
*Business Problem:
 Hospitals generate massive amounts of data daily, making it difficult to track costs, medications, and resource allocation efficiently using raw records.
*Goal of the Dashboard:
  -Monitors billing and medication trends by condition and age.
  -Analyzes doctor and hospital performance.
  -Identifies high-cost medical conditions and resource utilization patterns.
  -Supports strategic planning and budget optimization.


  (5) Walkthrough of Key Visuals
  💰 KPIs: Total billing amount (1.42bn), total admissions, and discharge counts.
  🍩 Billing by Medical Condition: Displays total billing distribution across major diseases.
  📊 Medication by Age: Shows medication count distribution across age groups.
  🏥 Doctor by Hospital (Pie Chart): Illustrates doctor distribution across hospitals.
  📈 Medication by Medical Condition (Bar Chart): Compares medication counts per condition.
  📉 Doctor by Hospital (Line Chart): Displays trends in doctor availability across hospitals.


  (6) Business Impact & Insights
  -Healthcare Cost Management: Identifies conditions with high billing amounts for cost optimization.
  -Medication Utilization: Tracks prescription patterns by age and disease.
  -Hospital Performance: Evaluates doctor allocation and hospital workload.
  -Strategic Decision-Making: Enables data-backed planning for better patient and financial outcomes.
